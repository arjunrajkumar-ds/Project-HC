01

Stage bar on /train

A sticky strip under the Train header that stays on screen while you scroll. Chevrons run Warm-up → T1 #1 → T1 #2 → (T2) → T3. Logging a set moves it forward automatically, and Next lets you move on yourself.

Simulate
  1. Pinned in place. It sits between the header and the date row with position:sticky; top:0, about 66px tall. The caption line says which stage you're on, which lift, and progress toward its target.
  2. Moving forward. Your first set in a stage makes it active (sheen), and the fill grows with each set toward the target. A set from a later stage marks everything before it done. Next finishes the current stage and moves on.
  3. Done animation. The fill completes, a light sweep passes across, the chevron flashes, and then the next one nudges in from the left. When T3 is active, Next becomes Finish and opens the recap in section 02.
  4. T2 is optional. It stays as a 13px dotted notch. Logging a T2 set unfolds it into a full chevron, and you can also tap the notch to open it. If it's folded, Next skips past it and the stage count drops to 4.
  5. T3 has three parts. SH / AR / CO each fill from the bottom in their muscle colour. Three sets fill a part, the same as the coverage meters. You can do them in any order.
  6. T1 #1 and #2 each take the name of the first different tier-1 lift you log. Tapping a done chevron jumps the exercise card back to that lift.

02

Finish recap: scheme dots filling

Tapping Finish (double-tap, same as now) opens a sheet with each laddered lift from today. It shows only the weight you used, with all its rungs. The new passes drop into their pips one at a time, and if a rung reaches the threshold (T = 5) it fills with colour. The numbers come from your history plus a sample session: OHP 4×5 @ 50, Skullcrusher 3×7 @ 30, DB Shoulder Press 3×6 @ 22.5.

Simulate
  1. When it plays. POST /api/gym/session/finish now also returns accumulation_delta, the scheme viz with and without today. The sheet runs entirely on that response, so nothing extra is fetched.
  2. What it plays. Lifts come in one by one (~0.9s apart). Rungs that didn't change are dimmed to 38%, so your eye goes to the pips that pop in, each with a small ring. The +N passes counter goes up with every pip.
  3. Mastery moment. When the fifth pip lands, the cell fills with accent colour, glows, and a MASTERED 3×7 tag pops in. The counter on the right bumps up.
  4. Rule change: finishing counts today. The home panel used before_today. It now also includes today when today's session is finished = 1. Logging another set reopens the session, which drops today out again.
  5. If nothing laddered was passed (cardio-only, or nothing met a rung), the sheet shows today's summary instead and skips the animation.

Two alternate accumulation views

Each one would be a 4th and 5th option in the home panel's Matrix / Bars / Rings toggle, built from the same scheme_viz data. View B also needs pass_days per exercise. They use your real history; switch exercises below.

  1. A · Route. The ladder drawn as a climbing route. Each floor is one weight (heaviest at the top), and each hold is a rung in TIER_BOUNDS order. The rope between holds lights up once you've mastered the hold below it, so a lit line shows work you can build on. A dashed next floor (+2.5 kg) sits above as the obvious next goal, and ▲ marks "you are here".
  2. Why A. The matrix answers "how much have I banked". The route answers "how far up am I, and what's next". It reads like a game board, which is the point.
  3. B · Ledger. This one is about time. Columns are training days and rows are rungs, with harder rungs higher up. Each dot is one pass, accent-coloured for that day's heaviest weight and grey for lighter ones. The white frontier line steps to the hardest rung passed each day, and weight jumps show above the column. Gaps over 3 weeks are marked.
  4. Why B. It's the only view that shows when things happened, so you can see if you stalled, went back to a lighter weight, or broke through. The tally on the right matches the matrix at the current weight.
  5. Recap tie-in. Both views mark today: a pulsing dashed column in B and new holds in A. So the home page picks up where the Finish recap stopped.
